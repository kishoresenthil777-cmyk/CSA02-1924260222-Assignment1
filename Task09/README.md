# Task 09: Electricity Billing Program

## Aim
To implement and test an electricity billing program using the given tariff structure.

## Tariff Structure
- First 100 units: Free
- Next 100 units: Rs. 2.25 per unit
- Above 200 units: Rs. 4.50 per unit
- Fixed charge: Rs. 50

## Requirements
1. Accept the previous and current meter readings.
2. Calculate electricity consumption, including meter rollover.
3. Calculate the bill according to the tariff slabs.
4. Use integer paise for accurate monetary calculations.
5. Validate input values and handle invalid inputs.
6. Display consumption and the final bill clearly.

## Testing
Test zero consumption, slab boundaries, higher consumption, and meter rollover. Compare the actual outputs with the expected results.

## Conclusion
A reliable billing program should calculate consumption correctly, apply the tariff slabs consistently, and avoid rounding errors.
