# Task 08: Compilation Process

## Aim
To understand the different stages involved in compiling a C program.

## Compilation Stages
1. **Preprocessing:** Processes header files, macros, and preprocessor directives.
2. **Compilation:** Converts the preprocessed C code into assembly code.
3. **Assembly:** Converts assembly code into object code.
4. **Linking:** Combines object code with required libraries to create an executable file.

## Testing
Compile and run the C program using a C compiler. Observe compilation errors and correct them before execution.

## Conclusion
Understanding the compilation process helps identify errors and produce a working executable program.
