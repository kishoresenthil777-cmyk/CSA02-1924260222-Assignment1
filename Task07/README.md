# Task 07: Type Conversion

## Aim
To understand implicit conversion, integer division, explicit type casting, and data loss during type conversion in C.

## Concepts
- **Implicit conversion:** C automatically converts one data type to another.
- **Integer division:** Dividing two integers produces an integer result, discarding the fractional part.
- **Explicit casting:** The programmer manually converts a value into another data type.
- **Data loss:** Converting a larger data type into a smaller one may lose information.

## Billing Application
Electricity charges should be calculated using integer paise to avoid floating-point rounding errors. Explicit type conversion must be used carefully to prevent incorrect billing amounts.

## Conclusion
Correct type conversion is important for accurate billing calculations and reliable C programs.
