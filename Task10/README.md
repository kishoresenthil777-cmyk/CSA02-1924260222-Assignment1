# Task 10: Expected Output vs Actual Output

## Aim
To validate the electricity billing program by comparing expected results with actual execution results.

## Testing Method
1. Identify the expected result for each test case.
2. Compile and execute the C program.
3. Record the actual output.
4. Compare the expected and actual results.
5. Correct errors and repeat the tests.

## Test Cases
- Zero units consumed.
- Exactly 100 units consumed.
- 150 units consumed.
- Exactly 200 units consumed.
- 350 units consumed.
- Meter rollover from 65535 to 0.
- Invalid input values.

## Validation
The program should apply the correct tariff slabs, handle meter rollover, reject invalid inputs, and calculate bills accurately.

## Conclusion
Comparing expected and actual outputs helps identify errors and verify the reliability of the billing program.
