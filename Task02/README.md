# Task 02 – Data Types

## Objective
To identify suitable C data types for the rural electricity billing system.

## Data Types Used

1. `int` – To store the number of electricity units consumed.
2. `float` – To store electricity rates and billing amounts with decimal values.
3. `char` – To store a single character when required.

## Conclusion
Choosing suitable data types helps store values correctly and perform electricity bill calculations.
